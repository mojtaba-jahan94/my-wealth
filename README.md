# 💰 MY Wealth — مدیریت هوشمند دارایی

یک اپلیکیشن تک‌صفحه‌ای برای مدیریت دارایی‌های نقدی و غیرنقدی در بازار ایران.

> بدون نیاز به سرور یا نصب — فقط index.html را باز کنید!

## امکانات

- قیمت زنده از TGJU: دلار، طلا ۱۸ عیار، سکه، یورو، درهم
- قیمت کریپتو از CoinGecko: BTC, ETH, USDT, BNB, SOL
- افزودن کانال تلگرام عمومی برای استخراج قیمت
- افزودن سایت دلخواه با Regex Pattern
- داشبورد: KPI، نمودار تاریخچه، نمودار دونات
- سود/زیان (P&L) با ثبت قیمت خرید
- هدف‌گذاری مقدار برای هر دارایی
- هشدار قیمت با Browser Notification
- مدیریت بدهی‌ها و ارزش خالص
- خروجی CSV و چاپ/PDF
- ذخیره‌سازی در localStorage

## استفاده

فایل index.html را در مرورگر باز کنید.

## فناوری

HTML5 | CSS3 | Vanilla JavaScript | Tailwind CSS | TGJU API | CoinGecko API
